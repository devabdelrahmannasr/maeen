# Delivery Workflow

Status flow: `Inbox → Ready → In Progress → In Review → Blocked / Done → Released`.

- Priority: P0, P1, P2, P3.
- WIP limit: one executable item in progress.
- Target task size: one to two days; split larger work.
- Every work item needs an owner, area, release, parent/dependencies, acceptance criteria, and verification evidence.
- Do not use `Blocked` for ordinary uncertainty; record the exact external dependency or missing decision.
- A work item is `Done` only after review and verification. A release item becomes `Released` only through its release gate.
