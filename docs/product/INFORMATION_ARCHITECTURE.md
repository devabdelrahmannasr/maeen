# Information Architecture

## Primary areas

- Onboarding
- Library
- Book and Reading Plan
- Goal and Protocol
- Active Session
- Learning Artifacts
- Progress
- Settings and Data

## Navigation principle

The product is a narrow side-panel assistant, not a multi-tool dashboard. Primary navigation should keep Library, current session, progress, and settings reachable while protecting focus mode from unnecessary choices.

## Core entities

Book → Reading Plan → Protocol Snapshot → Session → Session Steps → Learning Artifacts.

Settings, exports, imports, migrations, and backups support those entities without becoming part of the learning flow.
