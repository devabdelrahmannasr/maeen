# MVP Scope

## Included

- Arabic onboarding and local-privacy explanation
- Local book library and book metadata
- Goal and constraint selection
- Deterministic protocol selection and explanation
- Versioned Protocol Snapshot
- Guided reading session with resilient timer
- Recall, explain, review, question, and application notes
- Session summary and book progress
- Settings, accessibility preferences, export, import, backup, and deletion
- Chrome/Edge Manifest V3 Side Panel

## Excluded

- Reading or parsing PDF content
- Custom PDF renderer or annotations
- Backend, authentication, accounts, cloud sync, telemetry, or monetization
- AI, recommendations based on content, embeddings, or RAG
- Firefox, Safari, mobile, and Acrobat integrations
- Social or collaboration features

Any proposal that crosses this boundary requires an explicit product decision before implementation.
