# Reading Protocol Catalog

| Family | Intended goal | Building blocks |
|---|---|---|
| Deep Technical Reading | Deep conceptual understanding | P2R, Active Recall, Feynman, 50/10 |
| Exam Study | Exam preparation | SQ3R, Blurting, Review, Pomodoro |
| Practical Application | Apply knowledge quickly | 80/20, Structured Notes, Apply, Timeboxing |
| Deadline Reading | Finish by a deadline | Reverse Planning, pages-per-minute, Timeboxing |
| Critical Reading | Evaluate claims and reasoning | Questions, marginal-style notes, Review |
| Focus Recovery | Rebuild sustained attention | Short Blocks, Pomodoro, distraction tracking |

Protocol selection must be deterministic, explainable, tested as a decision table, and versioned. A rules update affects new plans only unless the user explicitly creates a new plan; it must not rewrite historical snapshots.
