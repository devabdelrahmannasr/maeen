# UI Inventory

| Screen | Primary purpose | Important states |
|---|---|---|
| Onboarding & Privacy | Explain value and local ownership | first use, returning user |
| Books Library | Start/resume book work | empty, populated, archived, loading |
| New Book Setup | Save metadata/reference | valid, invalid, duplicate-like warning |
| Goal Selection | Capture purpose and constraints | single goal, secondary goals, deadline pressure |
| Protocol Preview | Explain selected method | generated, changed constraints, unavailable rule |
| Focus Session | Present one next action | active, paused, break, distracted, recovered |
| Recall / Explain / Review | Capture learning output | draft, saved, validation issue |
| Session Summary | Confirm preservation and outcome | completed, partial, abandoned |
| Book Progress | Show progress and artifacts | no history, active plan, archived book |
| Settings & Data | Preferences and ownership controls | export, import preview/error/success, delete confirm |

The implementation must also cover dark theme and 320, 420, and 600 px widths without changing the product hierarchy.
