# Design System Handoff

## Direction

Calm, focused, trustworthy, Arabic-first, and structurally RTL. The visual language uses clear cards, generous spacing, a strong primary action, restrained supporting color, and explicit recovery messaging.

## Recorded visual tokens

The current source artifacts use a primary indigo around `#3157D5`, teal success/progress around `#16A085`, slate text, light neutral surfaces, amber visible focus, and rose destructive states. Treat the Figma page **01 — Foundations & Components** as visual truth and convert these references into implementation tokens only after `RES-004`.

## Required component families

Buttons; text fields and text areas; choices; cards; progress; timer; step list; top bar; status messages; modal/confirmation; empty, loading, error, recovery, and success states.

Native Figma variables and component sets are still pending. Do not infer that documentation frames are native reusable components.
