# Accessibility Requirements

- Use semantic HTML and structural `dir="rtl"`; do not mirror only with CSS transforms.
- Every primary flow must be keyboard complete with a logical RTL-aware focus order.
- Show a high-contrast visible focus indicator.
- Meet WCAG AA contrast for text and interactive states.
- Do not communicate status using color alone.
- Respect reduced motion and avoid motion required for understanding.
- Keep labels persistent; do not use placeholder-only inputs.
- Announce timer, save, error, import, and recovery changes without excessive live-region noise.
- Provide accessible names and touch targets suitable for the side panel.
- Test at 200% zoom and the documented 320, 420, and 600 px widths.
- Arabic copy must remain readable, direct, and free from layout truncation.
