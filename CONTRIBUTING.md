# Contributing

This project is not yet open for external contribution because the open-source license and implementation stack remain undecided.

For authorized local work:

1. Read `AGENTS.md`, `MEMORY.md`, `PRODUCT.md`, and `STATUS.md`.
2. Select one Ready work item from the authoritative Notion workspace.
3. Keep the change small and within the MVP boundary.
4. Add tests and run the relevant verification.
5. Record decisions, status, and any unresolved risk.
6. Do not publish, push a remote, or create a release without explicit approval.
